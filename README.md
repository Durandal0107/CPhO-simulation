# 物竞人生模拟器

原创中文网页养成游戏，参考 Faust-Huang 的每周规划、剧情选择和竞赛成长结构。无框架、无外部资源或运行时依赖，可离线使用。

## 本地运行

需要 Node.js 22 或更新版本。

```sh
npm run dev
```

服务默认监听 3000 端口，可通过 `PORT` 指定端口。`npm test` 验证24周完整流程、晋级、退赛路线和行动限制。

也可以把 index.html、style.css、app.js、game.js、storage.js 部署到任意静态站点（包括 GitHub Pages），保留相对路径。ES 模块需要通过 HTTP 服务访问。

## 玩法

选择两项天赋，在24周内分配学习、实验、文化课与休息行动。第8周预赛、第16周复赛、第24周国赛；未晋级仍可走完其他成长路线。每三周遇到剧情选择，进度自动保存在当前浏览器。结局可导出成长手记。

赛事阈值和奖项是简化的游戏机制，不代表真实 CPhO 赛制。所有剧情为原创。当前版本不包含账号、云端存档、真实题库或完整国家队选拔。

## 构建与发布

`npm run build` 生成可直接部署的 `dist/`。仓库已包含 GitHub Pages 工作流：把代码推送到 `main` 后，在 GitHub 仓库的 Settings → Pages 中将 Source 设置为 GitHub Actions，再运行工作流即可。公开网址以实际部署结果为准。本地创建工作流不等于已经部署。

自动保存包括尚未结算的本周计划。损坏或不兼容的存档会显示提示，且不会让页面崩溃。重开前会要求确认。当前版本包含8组原创剧情、6项天赋、6种行动、三级赛事和多结局。
