# 物竞人生模拟器

原创中文网页养成游戏：安排学习与休息、处理每日事件，经历预赛、复赛、国赛与不同人生结局。Node.js 22+，无第三方运行时依赖。

## 运行、测试与部署

- `npm run dev`：启动开发服务，默认3000端口，可用 `PORT` 覆盖。
- `npm test`：验证活动收益、每日事件、关系、天赋、计分与存档。
- `npm run build`：完成测试，再生成静态网站 `dist/`。

GitHub Pages：代码推送到 `main` 后，在 Settings → Pages 将 Source 设置为 GitHub Actions，运行 **Test and deploy GitHub Pages**。也可部署 `dist/` 到任何静态托管服务。ES模块须通过HTTP访问；不能直接双击HTML文件。

## 初始身份：人格面具

新开局必须选择1项身份，身份与天赋独立选择、乘法叠加；旧存档保留原版身份，不强行追加。

| 身份 | 效果 |
| --- | --- |
| 强省强校 | 预赛、复赛晋级线提高30%，学习正收益提高20%，所有心态损耗提高10% |
| 天赋怪 | 学习正收益提高15% |
| 一般路过 | 每回合行动点+2，与卷卷、恋爱、迷失叠加 |

学习收益指常规活动的力学、电磁、热学、光学、近代物理、实验、文化课正收益，不包含心态回复或事件奖励。强校预赛、复赛晋级线在基础线之上乘1.3，其他奖项线不变。身份、收益预览和晋级线均保存并在界面显示。

## 开局天赋

按《开局天赋.docx》设置9项天赋：正面必选1项、负面必选1项，中立可选0～3项。

| 类别 | 天赋 | 效果 |
| --- | --- | --- |
| 正面 | ！？卷卷？！ | 每天行动点+1 |
| 正面 | 大手 | 复赛20%概率不看分数直接晋级 |
| 正面 | 家财万贯 | 初始财富100，每7天财富翻倍、人缘+1 |
| 中立 | 赢在起跑线 | 增加6天准备期；准备期正收益减50%，正式24天正收益减20% |
| 中立 | 天生嘉豪 | 心态消耗减20%，初始人缘减2，每天10%概率出现专属事件 |
| 中立 | 破釜沉舟 | 文化课始终为0，五项理论能力及实验正收益翻倍 |
| 负面 | 坠机体质 | 正收益+25%；考试5%扣120、10%扣80、25%扣60、50%扣40、10%不扣分 |
| 负面 | 精神错乱 | 每次行动每项属性独立随机附加−5至+3，九种结果各1/9概率 |
| 负面 | 迷失 | 每天10%概率行动点−2、心态+5；当天结果保存，刷新不重抽 |

基础心态70、文化课65、人缘10。财富不限100，其他属性上限100。正收益倍率乘法叠加：坠机体质、准备期/正式期、破釜沉舟；嘉豪减耗只作用于负心态。精神错乱先随机偏移，再根据正负应用天赋倍率；事件不受精神错乱影响。文化课归零优先于所有加成。财富翻倍、人缘周期奖励与迷失的固定+5心态按天赋原值执行。行动卡显示天赋调整后的基础收益，手记记录实际随机收益。

预赛满分320，复赛与决赛满分400。旧存档参考线为预赛75、复赛125、集训队175、金牌166、银牌157；新开局使用该局独立校准线，坠机扣分后最低0。选择提前准备时比赛发生在第14、22、30天，普通开局为第8、16、24天。大手可无视复赛扣分后的成绩晋级。以上为游戏机制，不代表真实CPhO赛制。

## 每日活动与事件

每天基础6行动点，卷卷为7。同一活动可重复；未使用的点数不累积。非心态学习收益为初版的三分之一。基础心态变化：力学−5、电磁−5、热学、光学、近代物理−4、实验−3、文化课−1、散步+2；每天文化课自然−3、心态自然恢复+3（固定值，不受收益倍率影响），另受天赋约束。

每天结束后必须处理一个数值事件，包括最后一天。难题设对应能力门槛，未满足则不能攻克。恋爱每天固定占用1行动点、基础心态+2；至少3天后可能分手，基础心态下降25或35，次日恢复行动点，4天内不再出现告白。正负事件收益也受正收益/心态减耗天赋影响；按钮显示处理后的数值。

自动存档包含当天计划、随机行动点损失、待处理事件、恋爱与冷却状态。旧版本存档保留原来的六项天赋与100分制，不自动替换；重新开局才使用新天赋。结局可下载成长手记。当前无账号、云端存档或真实题库。

## 心态归零

任何活动或事件使心态归零时，立即停止本局，不再执行后续活动、回复、比赛或事件。显示加粗大字GAMEOVER，下方小字“这不是你的错。玩去吧。”。结束状态保存，刷新不会恢复本局，重新开局可开始新故事。

## 独立学科

热学、光学、近代物理独立显示、训练及出题，初始各15，基础每次训练+3、心态−4、消耗2行动点。理论成绩取力学、电磁、热学、光学、近代物理的平均值，理论占72%、实验占28%，再按心态和发挥计分。旧存档自动迁移：原合并热光数值分别保留给热学和光学，近代物理从15开始；既有成绩和进度不回溯修改。

## 每局开局校准

新开局时使用Web Worker在浏览器后台真实模拟1000名无天赋、随机身份角色。每局生成独立种子及24/30天事件日程，模拟角色共享玩家该局的日程与准备期长度，不再使用发布时的统一分数线。模拟选项与学习计划随机，能力门槛和心态归零规则仍然生效。按实际参加考试的前30%逐轮晋级，决赛前10%、30%、70%划定集训队、金、银线。

每日预设主事件和统一替代事件。恋爱事件要求单身且不在冷却，约会要求恋爱中，分手要求恋爱至少3天；条件不满足时使用该日预先生成的替代事件。模拟角色与玩家的选择可不同，但同样条件下必定看到同一事件、内容和门槛。玩家选择嘉豪时专属事件也纳入共享日程；模拟角色本身仍无天赋数值加成。

种子、完整事件日程、校准报告及本局五条分数线均保存于存档。继续、刷新、处理事件均不会重跑校准，重新开局才生成新世界。界面显示校准进度；校准失败会返回开局页面并说明原因，不会偷偷使用旧分数线。旧存档维持原有静态分数线及随机事件规则，需要重开才能体验每局世界。

`npm run calibrate` 保留为维护旧静态参考值的离线工具；`cutoffs.js` 和 `calibration-report.json` 是旧存档参考。构建及部署不再执行它。实际新局始终运行 `calibration-worker.js` 和共享的 `calibration.js`。

默认角色名为陈梓涵，可自行修改；输入留空也使用默认名。预赛或复赛未达晋级条件立即结束，不再结算该日突发事件或推进下一天；旧失败存档加载后同样结束。结束页保留考试成绩和手记导出。大手触发直通视为晋级。校准过程由模拟排名决定晋级，不按前一版阈值提前淘汰。

## 心态与考试发挥

新计分规则使用发挥系数 = 0.75 + 0.25 × 心态/100，学科加权总分乘系数后四舍五入，再扣坠机分数。心态100对应100%发挥、60对应90%、20对应80%。取考试时的心态（当日行动与自然恢复后、当日突发事件前），考试记录保留当时心态与系数；模型不会改变既有成绩。心态0时仍立即结束，不执行考试。大手的20%复赛直通继续保留。
