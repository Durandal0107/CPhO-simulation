# 物竞人生模拟器

原创中文网页养成游戏，参考 Faust-Huang 的每天规划、剧情选择和竞赛成长结构。无框架、无外部资源或运行时依赖，可离线使用。

## 本地运行

需要 Node.js 22 或更新版本。

```sh
npm run dev
```

服务默认监听 3000 端口，可通过 `PORT` 指定端口。`npm test` 验证24天完整流程、晋级、退赛路线和行动限制。

也可以把 index.html、style.css、app.js、game.js、storage.js 部署到任意静态站点（包括 GitHub Pages），保留相对路径。ES 模块需要通过 HTTP 服务访问。

## 玩法

选择两项天赋，在24天内分配学习、实验、文化课与休息行动。第8天预赛、第16天复赛、第24天国赛；未晋级仍可走完其他成长路线。每天结算后触发突发事件，进度自动保存在当前浏览器。结局可导出成长手记。

赛事阈值和奖项是简化的游戏机制，不代表真实 CPhO 赛制。所有剧情为原创。当前版本不包含账号、云端存档、真实题库或完整国家队选拔。

## 构建与发布

`npm run build` 生成可直接部署的 `dist/`。仓库已包含 GitHub Pages 工作流：把代码推送到 `main` 后，在 GitHub 仓库的 Settings → Pages 中将 Source 设置为 GitHub Actions，再运行工作流即可。公开网址以实际部署结果为准。本地创建工作流不等于已经部署。

自动保存包括尚未结算的本周计划。损坏或不兼容的存档会显示提示，且不会让页面崩溃。重开前会要求确认。当前版本包含8组原创剧情、6项天赋、6种行动、三级赛事和多结局。

## 每日突发事件

24天训练每天结束后都需处理一个事件，包括最后一天。所有选择都有数值影响；相邻两天不会出现相同事件。难题的攻克选项要求对应学科达到门槛（22 + 天数 × 0.9，取整），未达标时只能暂时放弃。

单身时可能遇到告白，可接受或拒绝。恋爱从下一天开始固定占用1行动点，并在每天结算时恢复2点心态；恋爱至少3天后才可能出现分手事件。分手会降低25或35点心态，次日恢复行动点，4天内不会再次遇到告白。关系、冷却和待处理事件随存档保存。

每日突发事件的数值独立设置，不受常规活动的1/3和心态1/2缩放影响。比赛仍在第8、16、24天进行，晋级线不变。旧存档可继续，已有数值保留；建议新开一局体验完整的每日事件。
